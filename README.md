<h1 align="center">Sprinkler Dash Card</h1>

A fully self-contained smart irrigation dashboard card for Home Assistant. Zero YAML scripting required — install the card, create your zone duration helpers, configure it in the card editor, and press **Set up** once to create the script and automation that do the watering.

## Features

**Zero setup scripting — and nothing changes without your OK**
- One **Set up…** button (admin only) creates `script.sprinkler`, `automation.sprinkler_controller`, one `timer.sprinkler_zone_N` per zone and the helpers (skip list, run queue, rain pause, manual run log) — and optionally a Scheduler entity
- It lists exactly what it will create or update and does nothing until you press **Confirm**. Just viewing the dashboard never changes your configuration
- It only ever updates a script or automation it created itself (marked *Auto-generated by Sprinkler Dash Card*). If `script.sprinkler` or the controller id already belongs to something else, Set up stops and tells you. Existing helpers and timers with the same names are reused, never modified
- When you change zones, sensors or rules, a banner offers **Review update…** to bring the automation in line

**Runs in Home Assistant, not in your browser (v3)**
- Every zone gets a restoring HA timer. Whenever a zone turns on — schedule, Manual Run, the zone toggle, the eWeLink/Sonoff app, or any other automation — the controller arms its timer and closes the valve when it runs out
- Scheduled runs are held in a persistent queue (`input_text.sprinkler_queue`). If HA restarts mid-run, the running zone still stops on time and the remaining zones carry on
- Valve-close is verified and retried up to 3 times, with a notification if a valve will not close
- A once-a-minute watchdog arms a timer for any zone found running without one
- Closing the dashboard, switching views, or a phone going to sleep can no longer leave a zone running

**Zone control**
- Up to 12 configurable zones with toggle, progress bar, countdown timer, and 1-minute adjustable duration
- Smart grid — 3 columns on wide cards when the zone count suits it (9 zones = 3×3), 2 on phones; the last row always stretches, so odd counts never leave a gap. Or pick 2 / 3 columns yourself
- Zone expand popup — tap any zone tile to open a large overlay with big +/− duration buttons, status, last activity, and a **Manual Run** button
- Manual Run auto-stop — pick a duration for this run only (the scheduled duration is not changed); the zone's HA timer closes the valve, even if the browser is closed or HA restarts
- Zone last-run badge — shows "last: Xm/Xh/Xd ago" on each tile
- Live countdown from the zone's HA timer, "Up next / Queued #n" badges during a schedule run
- Per-zone schedule toggle — tick/untick each zone to include or exclude from scheduled runs
- Per-zone skip next run — one-tap skip for the next run only, self-clearing after the schedule fires

**Schedule management**
- Built-in scheduler section — enable/disable, set run days, set run time with mobile-friendly HH/MM editor
- Optional **second schedule** with its own days and time — water morning and evening, or on different days at different times. The card shows each under its Scheduler name (rename a schedule in Scheduler and the card follows). With two schedules the header has one Start button per schedule plus Last Run, all the same width; rain pauses and restores each one, and a run that is still going is never restarted by the other schedule
- **Own minutes per zone for schedule 2** — tap a zone and set its *Evening duration* (or leave it at *Same* as schedule 1). Press **Skip** (or set it to 0) to skip a zone on schedule 2, so each schedule can water different zones. Each tile shows the schedule-2 minutes; changes apply immediately, no update needed
- Smart next-run countdown — shows "Tonight 22:00", "Tomorrow 06:00", or "in 3h 45m"
- Start Schedule button — manually triggers the full zone sequence
- Stop Schedule button — clears the run queue and closes all valves (with confirmation)

**Run history**
- Last Run popup — reads HA history for the most recent scheduled run and shows how long each zone *actually* watered (short runs highlighted), plus zones still queued, skipped, or that did not run
- Skipped zones and zones with no recent activity are shown in their own sections, so a zone that's quietly stopped running (e.g. toggled off, disconnected) is surfaced instead of hidden
- Manual runs are logged separately with a 🔧 icon, the duration used, and how long ago they ran — persisted in a helper (created by Set up) so they survive page refreshes

**Info bar**
- 4 configurable header slots — label, searchable MDI icon (7000+ with live preview), up to 2 sensors each
- Weather entities auto-render with condition and temperature
- Dual-sensor slots use unified dash separator (e.g. `4,650L - 97%`, `Possible - 55%`)
- All values title-cased automatically
- Tap any slot to open the entity detail popup

**Automation rules**
- Rain auto-disable — schedule turns off when rain crosses the configured mm threshold (runs in HA; slot turns yellow)
- Rain auto-restore — schedule re-enables after the configured hours once rain is back below the threshold; more rain restarts the countdown. Only restores a pause the rain rule caused — a schedule you switched off yourself stays off
- Pause countdown — schedule section shows "rain pause · resumes in Xh Xm"
- Tank low-level shutoff — all valves close and the queued run is cancelled when the tank drops below the configured % (runs in HA)
- Confirmation popups — optional confirmation before any zone or schedule action

**Settings**
- Full visual card editor — settings are saved by Home Assistant into the card you are editing, on any dashboard, inside stacks, with several sprinkler cards
- Drag-to-reorder zones — script run order matches
- Searchable entity picker for all entity fields
- A new card starts with empty entity ids (it pre-fills valve-like switches, a weather entity and a rain sensor it finds on your system)

## Installation

### Option 1: HACS (Recommended)

Sprinkler Dash Card is in the HACS default store.

1. Open **HACS** in Home Assistant
2. Search for **Sprinkler Dash Card**
3. Click **Download**
4. **Hard refresh** your browser (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac)

Then add the card from the dashboard card picker, or with:
```yaml
type: custom:sprinkler-dash-card-v2
```

<details>
<summary>Card not showing up in the HACS search? Add it as a custom repository</summary>

1. In HACS, click the **⋮** menu (top right) → **Custom repositories**
2. Paste `https://github.com/HybridRCG/sprinkler-dash-card`, select **Dashboard** as the type, and click **Add**
3. Search for **Sprinkler Dash Card** and click **Download**

</details>

### Option 2: Manual Installation

1. Download `sprinkler-dash-card.js` from the [latest release](https://github.com/HybridRCG/sprinkler-dash-card/releases/latest)
2. Copy it to `/config/www/sprinkler-dash-card.js` on your Home Assistant server
3. Go to **Settings → Dashboards → Resources**
4. Click the **+ Create New Resource** button
5. Paste: `/local/sprinkler-dash-card.js`
6. Set **Resource Type** to **JavaScript Module**
7. Click **Create**
8. **Hard refresh** your browser

Now add the card to any dashboard:
```yaml
type: custom:sprinkler-dash-card-v2
```

## Setup Guide

### Step 1 — Add the card

```yaml
type: custom:sprinkler-dash-card-v2
```

That's the only YAML needed — or add it from the card picker. All configuration is done in the visual card editor (edit the dashboard, then edit the card).

---

### Step 2 — Create duration helpers

Go to **Settings → Helpers → Add → Number** and create one per zone:

| Helper | Min | Max | Step | Unit |
|---|---|---|---|---|
| `input_number.valve_1_time` | 0 | 60 | 1 | min |
| `input_number.valve_2_time` | 0 | 60 | 1 | min |
| ... | | | | |
| `input_number.valve_8_time` | 0 | 60 | 1 | min |

Create up to `valve_12_time` for up to 12 zones.

---

### Step 3 — Install Scheduler Component

Install **[Scheduler Component](https://github.com/nielsfaber/scheduler-component)** via HACS (Integration category).

Set up (Step 8) can create a schedule for `script.sprinkler` for you. Adjust the run days and time directly on the card's Schedule section.

---

### Step 4 — Configure zones in the card editor

- Set **Active Zones** (1–12)
- For each zone: set **Switch Entity** (valve switch) and **Duration Entity** (`input_number` from Step 2)
- Drag ⠿ to reorder — script run order matches
- Tick checkbox to include zone in scheduled runs
- Save the card as usual

---

### Step 5 — Configure settings in the card editor

| Setting | Description |
|---|---|
| Nav path | Where tapping the title navigates |
| Rain sensor | Precipitation sensor in mm |
| Rain limit | mm above which schedule auto-disables |
| Rain restore | Hours before schedule re-enables after rain clears (default 48h) |
| Weather | Any `weather.*` entity |
| Jojo sensor | Water tank litres sensor |
| Jojo low % | Tank % below which all zones shut off immediately |
| Schedule switch | The `switch.schedule_*` entity from Scheduler |
| Schedule 2 switch | Optional second schedule (create one from the ⚙️ gear on the card). Per-zone minutes for it are set in each zone's popup |
| Zone columns | Auto (default), 2 or 3 |
| Notify | Optional notify service for tank-low / stuck-valve alerts |

---

### Step 6 — Configure info bar in the card editor

4 slots, each with: enable checkbox, label, MDI icon (searchable, live preview), Sensor 1, Sensor 2.

Layout auto-adjusts: 1=full, 2=50/50, 3=3-col, 4=2×2. Tap any slot to open entity detail.

---

### Step 7 — Automation rules in the card editor

| Rule | Behaviour |
|---|---|
| Confirm before activating | Confirmation popup on all zone/schedule actions |
| Rain: Auto-disable schedule | Disables schedule when rain exceeds limit |
| Rain: Auto-restore schedule | Re-enables schedule after rain clears (configurable hours) |
| Jojo: Low-level zone shutoff | Closes all valves when tank drops below low % |

---

### Step 8 — Set up (admin, one time)

Tap the ⚙️ gear on the card (or use **Home Assistant setup** at the top of the card editor) and press **Set up…**. The card shows what it will do, for example:

- Create helpers `input_text.sprinkler_skip_zones`, `…_manual_log`, `…_queue`, `…_rain_pause`
- Create `timer.sprinkler_zone_1` … one per configured zone (restoring timers)
- Create `script.sprinkler` (starts a schedule run)
- Create automation **Sprinkler Controller** (runs the zones, auto-off timers, rain and tank rules)
- Optionally: create a Scheduler schedule for `script.sprinkler`

Nothing is written until you press **Confirm**. Later changes to zones, sensors or rules show a banner on the card with **Review update…**, which only ever updates the script and automation this card created.

## Skip Next Run

Tap the 📅 calendar icon on any zone to skip it for the next run only. The zone shows an amber dashed border and "Skip next run" status. After the next schedule run, the skip clears automatically.

This uses `input_text.sprinkler_skip_zones`, created by Set up.

---

## Run History

Tap **Last Run** to see what happened during the most recent scheduled run.

- **Timestamp** — when the schedule last triggered (from `script.sprinkler`'s `last_triggered` attribute)
- **Watered** — actual on-time per zone from HA's recorder history (up to 6 hours after start). Zones that ran noticeably shorter than configured are shown in amber, e.g. `6m 46s of 9m`
- **Still queued** — zones waiting their turn while a run is in progress
- **Skipped / not scheduled** — zones marked "skip next run" or excluded from the schedule
- **Did not run** — zones that should have run but show no activity (or are unavailable)
- **Manual Runs** — any zones run manually via the zone expand popup, shown with a 🔧 icon, the duration used, and how long ago it ran. This is stored in the `input_text.sprinkler_manual_log` helper (created by Set up) so it survives page refreshes.
